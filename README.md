# DevOps Project 1 — First CI/CD Pipeline Lab

This is an early learning project where I explored how application builds, configuration management, containers and deployment tools work together. The repository contains my notes and screenshots from the exercise.

It is **a historical lab**, not a production-ready deployment or a current reference architecture.

## Tools explored

Java and Maven, Git and GitHub, Jenkins, Tomcat, Ansible, Docker, Kubernetes and AWS.

## What I learned

My main goal was to understand the different parts of a deployment pipeline rather than only run a sample application. This was my first attempt, so the notes reflect how I was learning each tool at the time.

## Limitations

- The setup has not been re-tested against current tool or cloud versions.
- Instructions are learning notes, not a turnkey build.
- I would now add clearer prerequisites, validation steps, version pinning and cleanup instructions.

I have retained the original materials to show what I worked on and how my understanding developed.
